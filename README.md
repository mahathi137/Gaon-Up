# Gaon Up

Gaon Up is an interactive web application that gamifies rural village development. Users can plan and manage resources across different sectors, track budgets, and optimize their village layouts in a fun and educational way.  

The platform simulates real-world challenges like limited resources and infrastructure planning, providing an engaging experience for learning about smart village development.

## Features

- **Interactive Village Planning**: Drag and drop resources like toilets, street lights, roads, and trees.  
- **Budget Management**: Track spending and optimize resource allocation.  
- **Mini Games**: Test your planning efficiency under time constraints.  
- **Knowledge Quiz**: Evaluate understanding of village development strategies.  
- **XP & Scoring System**: Earn points based on planning efficiency and quiz results.  
- **AI Chatbot Assistance**: "Maya" provides guidance and tips during gameplay.

## Installation

1. **Clone the Repository** 
```bash
git clone https://github.com/your-username/gaon-up.git
cd gaon-up
```
2. Install dependencies
```bash
npm install
```
3. Run the app locally
```bash
npm run dev
```
open your browser at
http://localhost:5173 to view the app.
